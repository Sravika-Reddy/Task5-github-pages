
# Task 6: Host a Static Website with GitHub Pages

## Objective
Deploy a simple static website using GitHub Pages.

## Technologies Used
- HTML
- CSS
- GitHub
- GitHub Pages

## Project Description
This project contains a personal portfolio website created using HTML and CSS. It displays an introduction, technical skills, projects, and a GitHub profile link.

## Deployment Steps
1. Created an index.html file.
2. Uploaded the website to a GitHub repository.
3. Enabled GitHub Pages in repository settings.
4. Selected the main branch and root folder.
5. Accessed the published website using its live URL.

## Live Website
https://sravika-reddy.github.io/task6-github-pages/

## Outcome
Successfully hosted a static website using GitHub Pages.
